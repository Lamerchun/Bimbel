# ios-chat

Native iOS chat app. Conversation UI first, WhatsApp-style, built in Swift.

Native iOS Chat-App. Fokus liegt auf dem Chat selbst (Konversation, Blasen, Composer, Keyboard), nicht auf Status, Anrufen oder Settings.

## Mitmachen

Issues und Pull Requests sind willkommen. Sinnvolle Einstiege:

- Chat-UI-Details (Bubbles, Timestamps, Reply, Reaktionen)
- Keyboard und Composer (inkl. Drag-to-dismiss)
- Accessibility und Dark Mode
- Tests rund um die Konversation

Bitte klein halten, an der Konversation bleiben, und Screenshots oder ein kurzes Repro mitliefern wenn es um UI geht.
