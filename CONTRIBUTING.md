# Contributing

Thanks for looking at Bimbel.

## Scope

This repo is the conversation UI of Bimbel, a native iOS messenger. In scope: chat thread, bubbles, composer, keyboard, replies, media in a thread. Out of scope for now: Status, Calls, Settings, backend/auth unless a chat feature needs it.

## How to help

1. Open an issue first if the change is more than a small fix.
2. Keep PRs small and focused on the conversation UI.
3. UI changes need a screenshot (simulator or mock).
4. Swift / SwiftUI, Xcode, iOS 17+ unless the issue says otherwise.

## Local setup

Xcode, then open the project once it lands on `main`. Until then, research and UI notes are the useful contributions.
